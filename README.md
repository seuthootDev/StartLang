# LangStart

When you start a language, there’s a pile of things you simply have to memorize — alphabet sounds, pronouns, numbers, months, “how do I say the time?” — the boring-but-essential stuff that textbooks keep sending you back to.

**LangStart turns that pile into short quizzes.**

You pick the language you’re learning, answer in *your* language, and keep going. Miss something? You’ll see it again until it sticks. No long lessons — just fast, focused repetition on what beginners need locked in first.

That’s the whole idea: **drill the must-know basics until they’re automatic.**

## Contributing

Almost everything you practice lives in plain **JSON** under `src/data/`.

If you spot a wrong sound, translation, or table cell — a typo, a bad approximation, a missing learner language — please fix it (or open an issue). Native speakers and careful proofreaders are especially welcome; datasets grow one correction at a time.

Thank you for helping learners start stronger.
